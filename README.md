# Plataforma web Aluna.bya

## Descripción del proyecto
Aluna.bya es una plataforma web desarrollada como proyecto académico de grado para apoyar la gestión comercial de un pequeño emprendimiento de repostería y postres ubicado en Tauramena, Casanare, Colombia.

La plataforma busca facilitar la administración de productos, clientes y pedidos, así como mejorar la experiencia de compra de los usuarios mediante un catálogo digital.



## Objetivo
Desarrollar una plataforma web que permita gestionar los procesos comerciales de Aluna.bya, facilitando la consulta de productos, la realización de pedidos y la administración de la información del emprendimiento.



## Funcionalidades principales

- Catálogo digital de productos.

\- Consulta de productos y precios.

\- Personalización de productos.

\- Carrito de compras.

\- Registro e inicio de sesión de usuarios.

\- Gestión de pedidos de clientes.

\- Reporte de pagos mediante Nequi.

\- Panel de administración.

\- Consulta y actualización del estado de los pedidos.

\- Gestión y validación de la información de los pedidos.

\## Instalación y configuración



1\. Instalar XAMPP en el equipo.

2\. Copiar la carpeta del proyecto `AlunaWeb` dentro de la carpeta `htdocs`.

3\. Iniciar los servicios Apache y MySQL desde el panel de XAMPP.

4\. Crear una base de datos llamada `alunabya`.

5\. Importar la estructura y los datos de la base de datos.

6\. Configurar el archivo local `conexion.php` con los datos de conexión correspondientes.

7\. Abrir el navegador e ingresar a:



&#x20;  `http://localhost/AlunaWeb/`



\## Base de datos



El sistema utiliza MariaDB para almacenar la información relacionada con los productos, usuarios y pedidos.



El archivo `conexion.php` contiene la configuración de conexión a la base de datos. Este archivo se utiliza localmente y no se incluye en el repositorio público por razones de seguridad.



\## Seguridad



Se implementaron medidas de seguridad como:



\- Validación de datos en el servidor.

\- Consultas preparadas para interactuar con la base de datos.

\- Control de acceso al panel administrativo.

\- Validación de tokens CSRF.

\- Validación de identificadores y estados de pedidos.

\- Verificación de productos, precios y personalizaciones desde la base de datos.
